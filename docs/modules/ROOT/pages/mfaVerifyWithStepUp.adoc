= mfaVerify(WithStepUp)

[.signature]
[subs="normal"]
----
AppDelegate.reachfive().mfaVerify(
    <<verifyStepUp,stepUp>>
)
----

== About this command

Verifies the step up process by passing the verification code and challenge ID.

The SDK exchanges the authorization code with the `redirectUri` passed to `AuthTokenFlow` in xref:mfaStartWithStepUp.adoc[], or with `SdkConfig.redirectUri` otherwise.

= startPasswordless

[.signature]
[subs="normal"]
----
AppDelegate.reachfive().startPasswordless(
    // Optional arguments
    <<email>>,
    <<phoneNumber>>,
    <<redirectUri>>,
    <<scope>>
)
----

== Description

Starts passwordless flow by sending an email or an SMS to the user with a single-use auth code.

The authorization code is bound to the `redirectUri` you pass here.
xref:verifyPasswordlessCode.adoc[] and the magic link handled by xref:addPasswordlessCallback.adoc[] exchange the code with that same URL, so you don't pass it again.

The token you get at the end of the flow carries the `scope` you pass here, or the SDK scope if you pass none.
